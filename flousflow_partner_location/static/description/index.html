Customer Geo Location

Save the exact geographic location of a customer / contact in Odoo 19 and reuse it instantly — open it in Google Maps or get turn-by-turn directions. No Google Maps API key required.

Key Features

  • Get Current Location — captures latitude, longitude and accuracy using the browser Geolocation API.
  • Extract Location — parses Google Maps / WhatsApp-shared links (including short maps.app.goo.gl links).
  • Open Location — opens Google Maps at the saved coordinates.
  • Get Directions — opens Google Maps turn-by-turn directions to the customer.
  • Clear Location — clears the saved coordinates after confirmation.
  • Reuses the standard res.partner fields partner_latitude / partner_longitude.
  • Automatic audit of Last Location Update and Updated By.
  • Manual editing limited to the Manage Customer Locations group.

How it works

Open a contact → Customer Location page → Get Current Location (device GPS) or paste a shared link and click Extract Location. Then use Open Location / Get Directions to navigate.

Requirements

Browser geolocation requires a secure context — serve Odoo over HTTPS in production.

Installation

Copy the flousflow_partner_location folder to your addons path and install the module from the Apps menu.
